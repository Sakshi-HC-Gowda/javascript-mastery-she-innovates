# Task 1 – JavaScript Basics

## 📌 Objective

The objective of this task is to understand the fundamentals of JavaScript by implementing basic programs using:

* Variables
* Data Types
* Operators
* Conditional Statements (`if-else`)
* Mathematical Calculations

---

## 📚 Concepts Covered

### 1. Variables

Variables are used to store data values in JavaScript.

Examples:

* `let`
* `const`

Example:

```javascript
let a = 10;
const pi = 3.14159;
```

---

### 2. Data Types

The following data types are used in this task:

* Number
* String
* Boolean (through conditional checks)

Example:

```javascript
let age = 20;
let name = "John";
let isEligible = true;
```

---

### 3. Operators

#### Arithmetic Operators

* `+` Addition
* `-` Subtraction
* `*` Multiplication
* `/` Division
* `%` Modulus

#### Assignment Operator

* `=`

#### Comparison Operators

* `>`
* `<`
* `>=`
* `<=`
* `===`

#### Logical Operators

* `&&` (AND)
* `||` (OR)

## ▶️ How to Run

### Using Node.js

1. Install Node.js.
2. Save the program as `task1.js`.
3. Open the terminal.
4. Navigate to the project folder.
5. Run:

```bash
node task1.js
```

The output will be displayed in the terminal.
